# Lumen Bank System - Project Statement

## Overview
Lumen Bank is a modular command-line banking application built in Python. It simulates a fully functional core banking environment allowing users to manage accounts, make deposits and withdrawals, calculate interest and taxes over time, take out multi-category loans with processing fees and GST, and export itemized statements.

## Key Features
- **Account Management**: Secure account creation with minimum opening balance checks.
- **Transactions**: Seamless deposits and dynamic withdrawal slips.
- **Loan System**: Multi-type loan offers (Home, Personal, Business, Education) with built-in EMI calculators, processing fees, and GST.
- **Time Simulation**: Fast-forward time engine that compounds savings interest while accounting for TDS tax deductions and loan interest accumulation.
- **Reporting**: Comprehensive transaction history and automated bill saving into a dedicated folder.
